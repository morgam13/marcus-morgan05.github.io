# NYC's RoofScape: Anatomy of the Skin

An interactive story walk through New York City's roofscape as an ecological, economic and social skin, with two case-study blocks: a hollow core block (Block 823, Sunset Park) and a solid core block (Block 787, Garment District).

## Files

- `index.html` is the whole site: page, styles, script and map data in one file.
- `img/` holds the drawings, models and survey images the page shows.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

Nothing is loaded from outside this folder.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload everything in this folder to the repository root, keeping `index.html` at the top level and the images inside `img/`.
3. In the repository, open Settings, then Pages.
4. Under "Build and deployment", set Source to "Deploy from a branch", choose the `main` branch and the `/ (root)` folder, then save.
5. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

## View locally

Open `index.html` in a browser.

## Typeface

The page asks for Helvetica Neue, then Helvetica, then Arial. Helvetica is a licensed font and is not included, so visitors see Helvetica only if it is installed on their device.
